# 模板

以下为占位符；公开记录不要包含秘密或私有路径。

```markdown
## 认领
- 目标 / 范围 / 排除项：
- 负责人 / 环境 / 基线提交：
- 依赖 / 验收标准 / 证据位置：
```

```markdown
## 交接：<来源> → <接手方>，<日期>
- 已完成 / 未完成：
- Issue / PR / 分支 / 当前 head：
- 工作区归属与未提交工作（按需脱敏）：
- 验证：命令、环境、结果、精确提交、运行链接：
- 未验证 / 风险 / 失败与基线：
- 依赖 / 阻塞 / 授权范围：
- 接手条件 / 下一步：
- 接手方确认：
```

```markdown
## 证据
- 结论与范围：
- 提交 / 事件 / 运行链接 / 时间：
- 通过 / 失败 / 跳过 / 排队的检查：
- 真人验收与实际参与者（如适用）：
- 局限 / 后续：
```
